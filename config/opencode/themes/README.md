# Themes Directory

Place custom UI themes in this directory.

## Format

Themes are defined in JSON or JSONC files:

```json
{
  "name": "my-theme",
  "colors": {
    "primary": "#ff6b6b",
    "background": "#1a1a2e"
  }
}
```
