# Plugins Directory

Place OpenCode plugins in this directory.

## Format

Plugins can be npm packages or local JavaScript/TypeScript files.

```json
{
  "plugin": [
    "opencode-helicone-session",
    "@my-org/custom-plugin"
  ]
}
```

See [OpenCode Plugins Documentation](https://opencode.ai/docs/plugins) for full details.
